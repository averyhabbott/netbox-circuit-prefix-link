# Changelog

All notable changes to this project are documented here.
This project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.2]

### Added
- Configurable columns for the Circuit and Prefix detail-page panels via `PLUGINS_CONFIG`
  (`circuit_panel` / `prefix_panel`). See the README for the available columns.

## [0.1.1]

### Added
- "Linked Prefixes" column on the core Circuits list table.

## [0.1.0]

### Added
- Initial release: link Circuits to Prefixes, with panels on the Circuit, Prefix, and
  IPAddress detail pages, plus a REST API.
